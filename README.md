# Simplicable index

An unofficial, searchable index of the featured article titles and topics listed on [Simplicable’s A–Z sitemap](https://simplicable.com/new/top).

Open [index.html](index.html) in a browser, or the GitHub Pages site:
**https://raammsathish003-lang.github.io/simplicable-index/**

This is not affiliated with Simplicable. All content belongs to Simplicable / John Spacey. The index includes only topic names, one-line section descriptions from the sitemap, and featured article titles — not article bodies.

Article URLs were not present in the sitemap copy used to build the page, so title and topic links use a Google `site:simplicable.com` search and are labelled as search links. The sitemap itself is linked directly.

## Coverage

- 48 A–Z topics and 7 additional sitemap sections (55 topics)
- 38 featured article titles listed on the sitemap page
- Source page: https://simplicable.com/new/top (attribution there: John Spacey, updated on March 09, 2026)
